# Root9 Stage2C / M4 prepublication package

This package publishes the M3-bound complete schema-valid Status26, the exact Root9 successor binding omitted from M3, and the sealed one-shot CAS/readback materials once they pass independent review. It does not contain or predict an M4 SHA; M4 identity is verified only after the Owner performs a normal GitHub web-flow merge.

The exact RuntimeAcceptance remains the unmodified M3 artifact at `work/recovery-root9/stage2b/RuntimeAcceptance.root9.json`. Its eight repair refs are under `accepted_subject.bounded_series_materials.repairs`; the existing generic repoint function expects another shape, so the sealed apply route must validate the exact eight refs and perform the one-time event append directly.

This carrier performs no live database access or write, no budget reservation, no capacity change, no refund, no attempt creation, and no GA dispatch. Publication is not live-apply authority.
