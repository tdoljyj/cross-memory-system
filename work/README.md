# work/

`work/` is **non-authoritative implementation staging**.

It may contain bounded intermediate material needed to complete an active engineering task, but:

- it is not Canonical Store, Current Truth, a release pointer or an accepted design registry;
- a file remaining here does not mean the work is current, approved, deployed or complete;
- new unbounded raw outputs, repeated archives and narrative reports should not accumulate here.

At closeout, move reusable implementation into the appropriate source/`development/`/`scripts/` location, durable machine evidence into `artifacts/`, and long-form narrative material to the governed document center. Disposable intermediates should not be committed.

See [Artifact Retention Contract v0.1](../development/contracts/repository/ArtifactRetention.v0.1.md).
