# Observed completion Source successor

This prepares the original model program's bounded local invocation against the
new e567 token-observation build. It supplies no public CLI, issuer, grant,
installed Host qualification or experiment permission. The original M0-M7 and
C1/C2/C3 obligations remain active.

The old completion wrapper requires input tokens before attempt consumption.
This successor instead requires the caller's separately adopted exact operation:
consume one attempt before model/backend load, then observe actual normalized
input tokens in that same process and enforce the approved bound before decode
or sample. Source preparation does not adopt this phase change for actual use.

`execute_observed_completion(plan, boundary=...)` fixes the exact nine candidate
runtime files, e567 patch identity, model/prompt/output-schema byte pins, private
new observation path, and budgets. It constructs only the fixed CPU arguments
and three observation flags. It forwards no API keys, proxy, download, arbitrary
arguments or interactive commands. All file and runtime namespaces, including
the system DLL boundary, still require the caller's real isolation acceptance.
The concrete Source build/static imports are not that acceptance.

The caller independently checks fresh exact Profile, Binding, subject, task,
phase, revocation, source and deadline at preflight, consumption, dispatch,
before-resume, running and result boundaries. The callback receives
`boundary(phase, frozen_plan, plan_sha256, opened_object)`, with `opened_object`
None at preflight and the same-process handle/device/inode/link/initial-size
facts after the new-only open. These are facts to validate, not an ACL or
currentness proof. Mutation of either copied view is rejected. The caller
validates the actual opened object before consumption and keeps its namespace
stable for the operation. Its consume operation must atomically reserve
one attempt. A callback returning None, a supplied hash or a local test callback
does not prove live authority. Late/unknown consumption never launches or retries;
the caller settles its original reservation.

The parent opens a private new-only observation file and passes that single
handle through Windows STARTUPINFO's handle list, alongside required process
stdio. The owned child starts suspended, is assigned to a kill-on-close Job and
is resumed only after the parent inheritance flag is reset. Unrelated inheritable
handles are closed from this child. The trusted Host must serialize all launches
that can inherit handles; this library cannot coordinate unrelated os.system or
other process-launching code. A local handle list cannot prove the entire Host
boundary. Source tests use finite non-model child processes and hypothetical
runtime identities only.

Original stdout/stderr and observation bytes remain evidence. Overflow retains
a marked prefix; read or close errors cannot create a complete observation or
erase a retained capture. Job cleanup, process outcome, capture completeness
and source parsing are distinct. File/spawn/cleanup syscalls may block beyond a
deadline; late returns prevent later consumption or resume, but this Source
does not guarantee interruption of an arbitrary blocking OS operation.

`parse_runtime_observation(raw, expected_limits=..., binding=...,
verify_binding=...)` is a pure byte parser for this exact Source record format.
It checks LF JSONL, exact fields and types, finite UTF-8 JSON, event sequence,
monotonic tick order, actual input frame, sampled ordinals/IDs/EOG and terminal
count/reason consistency. Complete stream consistency supplies three candidate
token counts; it does not establish process success or authenticate provenance.
Non-normal, malformed, incomplete or unverified streams retain raw evidence and
gaps. EOG is included in the sampled count, even if its piece is not displayed.
The caller must bind that count convention to its exact request/usage policy.

The parser's callback is externally trusted and must bind raw/source/runtime/
plan/currentness independently. Local string references and a callback result
remain unqualified here. No costs, elapsed times, bytes, currency, privileges,
Gold, thresholds or business status are inferred. Existing v2 construction must
combine genuine process closure and complete measured observations. The original
b11033 byte adapter's runtime pins are incompatible with this build; it must
receive a reviewed successor binding before this candidate can supply actual
v2 result bytes.

Actual model execution is still blocked by fresh exact experiment authority and
the real qualified caller/installation/isolation integration. Old M1/T0/T1
windows and VM permissions remain terminal. Source tests never become model
measurements, Provider qualification, DataGate, activation or M7 completion.
