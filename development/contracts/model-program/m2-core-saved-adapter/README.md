# Core saved-output adapter

`CoreSavedAdapter` accepts the caller-verified original e76 scorer module,
original source/contract/saved bytes, and the pinned scorer SHA. `snapshot(split_id)`
and `callbacks()` connect its original `score_saved` and renderer to `run_saved`
and `saved_harness`; callbacks are plain functions compatible with their data
deepcopy. No parser, schema, reference or exact-match rule is replaced.

The original 24 DEVELOPMENT source examples have no actual runtime status,
usage, formal Gold or calibrated probabilities. Original correct flags remain
`CANDIDATE_REFERENCE_COMPARISON` in `legacy_core_score` / `legacy_report`;
numeric labels, correct, probabilities and measurements remain missing.
`SAVED_CANDIDATE_OUTPUT` denotes an engineering source artifact only.

`CoreSourceIdentity.e76.json` pins 16 original Git blobs under
`tests/fixtures/model-stage-admission/core-adapter-e76/`. This independent public
engineering source/spec closure is `NONE / NOT_ISSUED`; it does not extend the
old 26-file lock, register a fifth scoped consumer or grant formal read/data/model
qualification. The original validator's internal deterministic consistency check
remains; no standalone generator, original fixture rewrite or model call occurs.

Caller authority, currentness, source verification and callback purity remain
external prerequisites. The added eight repository tests use real original
scoring and current replay/harness, while preserving candidate-only qualification.
