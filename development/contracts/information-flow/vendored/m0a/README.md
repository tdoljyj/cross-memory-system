# Vendored IF-MVP0-A files

Byte-identical copies of files from the frozen M0-A parent (delivery root
`d238cc438301a93ba5cf922b59d53efbe177f22d1c4918ea92218942b423d12b`).
`SHA256SUMS.m0a-subset` lists the lines from the parent's own SHA256SUMS
(schema paths shortened to this directory). Never edit these files. A change
means a new M0-A version, not an edit here.

They bind the Information Flow candidate store to the frozen contract (see
`../../M0DCloseout.v0.1.md` §4.2) and are checked by
`apps/clued-cloud/tests/information-flow-candidate-store-db.test.mjs`.
