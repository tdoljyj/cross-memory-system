# ADR-R3-005：版本命名空间矩阵（Gate 1 冻结）

- **状态**：DRAFT（Gate 1 裁决要求：建立版本矩阵，不机械统一）
- **裁决依据**："三个版本号不应直接强制统一……只有同一命名空间内发生冲突才修正，禁止为了'数字一致'机械改成同一版本。"

## 1. 版本矩阵（四命名空间）

| 命名空间 | 载体 | 当前值 | 语义 | 变更触发 |
|---|---|---|---|---|
| **产品版本** | `VERSION` 文件 | `vNext-2.0` | 产品/计划发布基线（vNext-N.M 序列） | 发布新版本、计划里程碑 |
| **协议版本** | `protocol-manifest.json` `protocol_version` | `vNext-1.3` | 双端同步协议行为契约版本（sync 协议语义） | 协议行为矩阵变更（manifest 先行） |
| **组件/CLI 版本** | `clued/` 运行时 `protocol_version` + `controller.py` | `0.3.0` | Clued 组件协议实现版本（独立语义版本） | 组件能力变更 |
| **Artifact manifest schema 版本** | `MANIFEST_SCHEMA_VERSION`（dist/manifest.py）+ `protocol-manifest.json` `schema_version` | `1` | artifact/协议清单 schema 兼容层 | schema 不兼容变更（升 major） |

## 2. 各命名空间的独立演化规则

1. **产品版本（vNext-2.0）**：与协议/组件版本**无绑定关系**。产品可以 vNext-2.1 而协议仍 vNext-1.3（实现未变）。
2. **协议版本（vNext-1.3）**：只随 `protocol-manifest.json` 行为矩阵变更而变。当前与产品版本不同步是**正常状态**，不是缺陷。
3. **组件版本（0.3.0）**：Clued 内部语义化版本。`clued/controller.py` 的 `protocol_version=0.3.0` 表示该组件实现的协议级别，未来可高于/低于协议清单版本（兼容性由组件自身校验）。
4. **Schema 版本（1）**：只在不兼容变更时递增。

## 3. 什么算"同命名空间冲突"（必须修正）

| 情形 | 判定 | 处理 |
|---|---|---|
| `protocol-manifest.json` 声明两个不同 protocol_version 字段 | 同命名空间冲突 | 修正为一个值 |
| 同一 manifest 内 `schema_version` 与读取端期望不一致 | 同命名空间冲突 | 升级或修正 |
| Clued 组件内部同时存在两个互斥的协议版本常量且都被使用 | 同命名空间冲突 | 统一 |
| `VERSION` 文件与 git tag 的产品版本语义不一致 | 产品命名空间冲突 | 按发布纪律修正 |

## 4. 什么算"跨命名空间差异"（禁止机械统一）

| 情形 | 判定 | 处理 |
|---|---|---|
| VERSION=vNext-2.0 vs protocol=vNext-1.3 vs clued=0.3.0 | **正常差异** | 维持，记录在本矩阵 |
| schema_version=1 vs 产品版本 vNext-2.0 | 正常（schema 独立演进） | 维持 |

**规则**：Gate 1 及以后**禁止**为了数字一致把协议版本改成产品版本，或把组件版本改称 vNext 序列。差异由本矩阵文档化，成为可审计的既定状态。

## 5. 版本消费方（实现侧）

| 消费方 | 读取 | 校验 |
|---|---|---|
| `memory_engine/dist/manifest.py` | `MANIFEST_SCHEMA_VERSION=1` | manifest 内 schema_version 必须匹配 |
| `clued/manifests.py` | `NODE_SCHEMA` | 节点 manifest schema 匹配 |
| `sync-memory.py` / `sync-memory.ps1` | `protocol-manifest.json` | 行为矩阵契约（只读） |
| Gate 1 Truth Provider | `VERSION` 文件 | 只读上报（`PRODUCT_VERSION` claim） |

## 6. 结论

当前三处版本号（vNext-2.0 / vNext-1.3 / 0.3.0）属于**三个不同命名空间**，无同命名空间冲突 → **不修正**。Gate 1 交付本矩阵作为唯一版本事实源，任何后续 Gate 的版本改动必须先更新本 ADR。
