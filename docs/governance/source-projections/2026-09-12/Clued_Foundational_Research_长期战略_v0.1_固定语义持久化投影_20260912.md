## 1. 战略地位

Clued Foundational Research 从现在起成为与工程/产品并列的长期一级战略主线。

基础研究：

- 长期、不间断；
- 不随某个产品阶段结束；
- 不设整个体系永久 COMPLETE；
- 各具体课题可以形成阶段成果、Stable Model、Production-Adopted Result 与 Open Problems。

## 2. GIKAO

GIKAO — General Information, Knowledge, and Action Ontology / 通用信息、知识与行动本体，是核心理论主轴，但不等同于全部基础研究。

核心对象包括：

Information / Claim / Evidence / Knowledge / Acceptance / Authority / Canonicality / Currentness / Context / Decision / Actionability / Authorization / Action / Effect / Receipt。

重要区分包括：

- Truth ≠ Confidence
- Confidence ≠ Evidence
- Evidence ≠ Authority
- Authority ≠ Truth
- Acceptance ≠ Truth
- Canonicality ≠ Truth
- Knowledge ≠ Actionability
- Capability ≠ Authorization
- Current ≠ True
- Current ≠ Frozen
- Accepted Candidate ≠ Canonical Committed

## 9. Gate 关系

基础理论不普遍阻塞工程。

但当核心工程能力依赖尚未稳定的基础概念时，对应阶段性理论成果必须进入设计/冻结 Gate。

例如：

- GIKAO Authority → Canonical Authority Core Gate；
- Context Science → Context Compiler Gate；
- Action Theory → Agent Action / Automation Gate。

原则：

> 不要求理论最终完成，但不能在核心理论仍明显自相矛盾时冻结长期工程合同。
