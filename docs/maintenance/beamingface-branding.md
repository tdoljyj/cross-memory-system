## Domains and release boundary

The adopted domain names are configuration targets, not evidence of live
binding. Existing operational links, Connect-generated URLs, Google callbacks
and OAuth origins retain their working routes until a separately verified
cutover. No credentials are copied to a new audience. Share-card assets also
stay on the configured serving origin so a display-name release cannot produce
links to an unbound host. Update the metadata origin with the verified domain
cutover and check `/og.png` there.

This branch does not rename the GitHub repository or deploy, re-register an app,
modify DNS/Google OAuth settings, reinstall a local plugin, or edit the resource
center's deferred main entry. Existing production acceptance gates still apply.
