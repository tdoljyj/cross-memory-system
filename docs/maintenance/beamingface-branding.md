Connect page and generated packages, Codex package, Claude Code marketplace
metadata, and engineering entry documents use BeamingFace. The homepage uses
“好的发现，会写在脸上。” and the accepted introduction without AI marketing terms.
Technical AI/Agent capability and permission explanations remain accurate.

Stable identifiers stay unchanged: the `cross-memory-system` repository,
`apps/clued-cloud`, `apps/kooyumi-connect`, package IDs, `clued` Skill ID,
`clued_*` tools/RPCs, schemas, storage keys, Worker names, workflow step names,
registered apps, and existing OAuth issuer/resource pairs. Prior fixed
disclosures, captured production sources, migration history, accepted evidence,
and read-only canonical exports keep their original bytes and meaning.
`KooYomi` inside an issued Connect Skill's `name` is an installed compatibility
identity; its description and visible branding use BeamingFace.

## Domains and release boundary

The adopted domain names are configuration targets, not evidence of live
binding. Existing operational links, Connect-generated URLs, Google callbacks
and OAuth origins retain their working routes until a separately verified
cutover. No credentials are copied to a new audience. Share-card assets also
stay on the configured serving origin so a display-name release cannot produce
links to an unbound host. Update the metadata origin with the verified domain
cutover and check `/og.png` there.

This branch does not rename the GitHub repository or deploy, re-register an app,
modify DNS/Google OAuth settings, reinstall a local plugin, or edit the resource
center's deferred main entry. Existing production acceptance gates still apply.
