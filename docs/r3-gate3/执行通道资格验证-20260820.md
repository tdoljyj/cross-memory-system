## 1. 通道设计（精确）

```
caller（宿主 Bash/PowerShell，短命令）          worker（独立 Python 进程）
  │  python trial_worker.py                       │
  │  --run-id <uuid> --state-root <root>          │ 1. acquire_lock（O_EXCL 原子创建）
  │  --binding <bid> --receipt <path>   ────────► │    lock 存在+done=False → ALREADY_RUNNING(exit 3)
  │    （立即返回，不等待）                         │    lock 存在+done=True+同 run_id → ALREADY_DONE(exit 0, 返回已有 receipt)
  │                                               │    lock 存在+done=True+异 run_id → 清除旧 lock，允许新 run
  │                                               │ 2. TrialRunner.install_once（INSTALL_LIMIT=1）
  │                                               │ 3. 收尾断言：journal 零 + binding 完整
  │                                               │ 4. receipt 原子写（tmp+os.replace；exit_code/pid/run_id/install_calls）
  │                                               │ 5. lock done=True（保留为运行证据）
```

## 2. 资格验证证据（tests/test_trial_worker.py，12 项）

| 资格 | 测试 | 证据 |
