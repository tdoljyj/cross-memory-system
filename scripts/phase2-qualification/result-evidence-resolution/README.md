# Original result evidence resolution

This module concretizes the interior of the existing immutable Evidence index. It creates no store, Receipt type, authorization or test outcome. `checkResultEvidenceStructure` consumes the complete original GA, actual same-domain reservation/readback, a complete proposed GRR, and the exact independently accepted static test suite bytes.

The compact JSON index uses `format: EXACT_ORIGINAL_EVIDENCE_INDEX_V1`, exact `ga_id` and `ga_sha256`, executor/fixture/input/revision bindings, `artifacts: [{uri,sha256,raw}]` and `tests: [{test_id,observation_refs,oracle_assessment_ref}]`. Artifact and index locators are explicit proposed content addresses `urn:clued:execution-evidence:<root_id>:<sha256>` resolved only against the actual reserved original index bytes. They are not new network endpoints or historical wire spellings. Index entries do not contain their own digest. Conflicting addresses, missing original bytes, changed hashes and duplicate/omitted tests are rejected.

Each actual observation binds its test and original GA and retains a source's exact raw bytes/hash. An oracle assessment independently binds the actual observations, the original static expected-outcome hash, full Test definition digest and result. The module never evaluates behavior by matching the Chinese oracle sentence or a fixture string. It returns the required full signed assessment bytes for the existing trusted GitHub verifier to authenticate; a reviewer label, this diagnostic, or an arbitrary signed document is insufficient. The accepting runtime must bind the actual delegated independent reviewer and publication to these exact bytes before final GRR admission.

The reserved decision must equal the proposed result and test list. All claimed PASS tests must cover the exact 19 applicable definitions, with PQUAL-18 excluded. The existing complete GRR schema, live Root/GA/revocation checks, unique STOP evidence, actual independent review, original signature and one terminal SQL CAS remain mandatory upstream/downstream checks. This module returns no transferable verifier token and performs no effects.
