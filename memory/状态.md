### 新会话处理规则（记忆携带机制）
- 新会话 ≠ 完整记忆：AI 只携带「已写入记忆文件的长期信息」，不携带聊天记录与过程细节；记忆文件是唯一跨会话数据源
- 开场先读前对齐，再完整读取记忆文件（画像 / 状态 / 决策 / 待办，归档按需查），据此理解身份、审美、决策与当前进度后再行动，不要求用户重新自我介绍
- 过程性内容（试过的方案、纠结过的名字、吐槽过的点子）不默认延续；一旦形成结论 / 决策 / 新进展 / 否决项，立即写回对应文件——关键节点不等会话结束，收尾再统一复查补写
- 只沉淀稳定、长期、未来仍适用的信息；一次性临时信息（买哪个手柄、某次临时计划）不写
- 目标：每次新会话都像同一个「项目记忆型搭档」，而不是从零认识的陌生人
